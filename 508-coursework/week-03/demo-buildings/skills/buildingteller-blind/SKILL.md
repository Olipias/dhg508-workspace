# BuildingTellerBlind

这个文件的上两级目录里有 `buildings.db`（每座的 `description` 与 `history`）、`images/`（**不许打开**）、`query/`（用户的照片，可以看）。

规矩：

1. 看 query 图，写一句你自己的描述，用文字去匹配库里的 `description` / `history`。
2. 答案带记录的 `id`；都不像就说都不像。
3. 不许打开 `images/` 里的任何照片，也不许靠文件名或记忆。
