## 说明

- `raw/` 只存了两个**正文快照**（S1、S2）用于回源核对；其余来源以 URL 引用，
  未下载原件（部分站点当时不可达，或为避免大文件入 Git）。
- S4 内容来自搜索引擎快照：`sxgo.cc` 在采集时返回 502，故其条目属**弱证据（E-C）**。
- 所有条目都是"**某来源如此描述**"，**非用工事实认定，也非穷举**；企业作息以其官方最新说明为准。
- 数据库由 `data/*.csv` 重建（`python3 code/build_db.py`），`*.db` 不入 Git。
