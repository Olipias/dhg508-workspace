# 秦代迁陵基层行政 2D 场景模拟 Skill

## 1. 适用任务

当用户要求构建“秦代基层小吏”“迁陵县”“里耶秦简”“睡虎地秦简”“稟食/名籍/文书/邮驿/仓廪”相关的 2D 可行走历史模拟时，使用本 Skill。

目标不是写历史小说，而是把简牍和律令中的**行政程序**转化为：
- 可操控角色行走的 2D 街道场景；
- 有信息边界和史料出处的 NPC 对话；
- 有程序链和可验证后果的事件；
- 玩家必须通过对话、查看简牍、核对名籍、登记封泥等交互才能拼出的制度知识。

## 2. 硬约束

1. 每个 NPC 的每类对话、每个可触发事件，必须能指回具体史料出处。无法指回的内容不得生成。
2. 禁止生成“智破大案”“为民抗命”“官场反转”“秦始皇微服私访”“刺客刺秦”等影视化情节。冲突必须来自制度缝隙：名册与人口对不上、文书时限与道路实情冲突、律令要求与地方操作不一致。
3. 不得让 NPC 直接说出“秦代实行编户齐民”这类概括结论。玩家必须通过核对名籍、处理冒领、登记封泥、写爰书，自己拼出制度如何运转。
4. 每个事件必须有程序链（至少 4 步）和可验证后果：玩家的选择影响文书是否合规、上级是否驳回、责任落在谁头上。
5. 度量、称谓、文书格式、官职名以里耶秦简和睡虎地秦简用字为准，不得用后世简化称谓替代。
6. 视觉上禁止交付纯色方块、Godot 默认图标、无阴影平铺、无边缘过渡的占位场景。占位资源必须标记 `PLACEHOLDER`，交付前全部替换。

## 3. 时空与角色设定

- 时间：秦王政二十七年至二十八年前后，迁陵县刚纳入秦制不久，基层行政处于磨合期。
- 地点：洞庭郡迁陵县，治所在今湖南龙山里耶古城，东临酉水，城址长方形，有夯土城墙和护城河。
- 玩家角色：喜，身份为令史，在县廷诸曹中供职，负责文书起草、簿籍核对和部分司法程序。令史身份、职责和工作方式依据秦简；调动到迁陵为虚构设定，但必须明确标注为虚构。
- 玩家不是侦探，而是被文书和程序推着走的基层吏员。

## 4. 地图节点

每条街是一个独立 Scene。房屋由 Agent 按秦代迁陵建筑特征生成，但只有下列节点挂载可交互 NPC 和事件。

- 县廷：核心文书中枢。玩家接主线、提交文书、接受驳回或核准。内部区分“曹”和“官”系统。
- 仓：粮食出纳枢纽。仓啬夫/仓守、佐/史、禀人三方经手，令史或令佐监督，报县令或县丞批准。
- 都乡乡部：乡啬夫和里典掌握直接人口信息，但名册常滞后于实际。
- 邮亭/传舍：封缄、用印、登记、传递时辰、封泥完好性、误期追责。
- 市/里门：轻量交互点，提供量器校验、债务纠纷、问路等碎片信息。

多地图通过城门、里门或酉水渡口切换。每张地图 2-3 个可交互节点即可支撑一段完整程序链。
