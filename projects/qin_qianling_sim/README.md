# 迁陵 · 廿六年五月

## 故事

公元前 221 年，洞庭郡迁陵县。你叫喜，新来的令史，第一天上班。

守丞敦狐把一份报案拍在你桌上：仓里死了个吏，叫丙——一个用《封诊式·经死》验尸模板虚构的案子。里典说是上吊。

「你去验。」敦狐说，「验成自杀，他老婆孩子没事；验成他杀，整个里都要脱层皮。可你要是验错了，脱皮的是你。」

你连尸首都没见过。

- 引擎：Godot 4.7（GDScript，2D 俯视）+ 纯网页版（HTML/CSS/JS，无框架）
- 人物：6 个主要 NPC 接 DeepSeek（守丞敦狐、仓啬夫是、都乡守嘉、里典午、丙妻、邮人得）；世界裁定，模型只负责说话
- 史料：睡虎地《封诊式·经死》《封诊式·贼死》《法律答问》《行书律》；里耶简作账目/户籍格式参考
- 美术：全部程序化生成（PIL），无第三方素材

## 怎么玩

1. **县廷**：看里典的报案，读《封诊式·经死》的验尸清单；守丞要你定：这条命算哪一种死。
2. **仓**：验尸（舌出、绳痕、矢溺、后脑淤伤、粮袋血），查账（少了三十石），问仓啬夫——后脑的伤要他的证词才入案卷。
3. **都乡**：问丙妻（他说「账对不上，他们要拿我顶」）、问里典（他那晚进过仓）、调丙的户籍。
4. **邮亭**：封好案卷，问邮人得送郡时间——时间要他的证词才入案卷；他可能求你写早半刻。
5. **回县廷**：交案卷。选 **自杀 / 贼杀 / 斗杀 / 死难审**；写不写里典/四邻、仓啬夫，也由你。

不懂名词就按 `H` 看「名词小抄」：经死、爰书、贼杀、斗杀、死难审、四邻/典老、封泥，全用一句人话解释。

**证据不是点一下物件就自动到手**：后脑的伤要问仓啬夫，送郡时间要问邮人得；没问到，案卷里就没有这一项。每个判法都至少要和一个 NPC 问到关键证据，才能交得上去。

两版右上角都有**小地图**：标出县廷、仓、都乡、邮亭，以及 NPC 点和你自己的红点；顶部 HUD 也放大了。地图是**示意图**，只负责导航，不是考古复原。

## 为什么是模拟，不是电影

电影可以拍到一具吊着的尸体，再给一个「自杀」或「他杀」的结论。它拍不到的是：你先看哪一处伤、信谁的话、把里典写不写进案卷、把「斗杀」写成「贼杀」还是「死难审」。

同一具尸体，四种写法：

- **自杀**：案子结了，仓里的账没人查，丙妻和孩子暂时安全；三个月后，丙的弟弟递状纸。
- **贼杀**：立案，仓啬夫和里典被拘，三十石的账翻出来；你写对了，但没人谢你。
- **斗杀**：你以为能替人减罪，守丞一句「斗杀人，廷行事为贼」把它改成贼杀。
- **死难审**：你写「验不明白」，案卷送郡里，迟迟没有回音；你没冤枉人，也没替人申冤。

这些选择不是「选结局」，是**选你把哪些字写进案卷**。秦代基层的「真相」，先是一份可复核的文书；电影只能给你看其中一份。

## 跑起来

```bash
# 1. 启动 NPC 服务（需要 DeepSeek key；只从环境变量读，不写入仓库）
cd projects/qin_qianling_sim
export DEEPSEEK_API_KEY=sk-...
python3 server/npc_server.py

# 2. 另开一个终端，启动游戏
godot --path game
```

没有 key 也能跑：把 `server/npc_server.py` 用 `--mock` 启动，或在游戏里让服务不可达——每个 NPC 都有脚本回退台词，主链仍然可完成。

```bash
python3 server/npc_server.py --mock          # 无网络演示
python3 server/npc_server.py --ask xiang "年籍呢？"   # 命令行问一句
curl http://127.0.0.1:8787/stats             # 调用次数/Token/估算费用
```

## 网页版（不需要 Godot）

```bash
cd projects/qin_qianling_sim
export DEEPSEEK_API_KEY=sk-...
python3 server/web_server.py --host 0.0.0.0
# 浏览器打开 http://127.0.0.1:8788
```

同一个 `game/data/*.json`、同一张地图、同一套 AI 服务；`web/` 只是把 Godot 的行走、对话、文书、证据和驳/准用 HTML/CSS/JS 重写了一遍。没有 key 时加 `--mock`，用回退台词也能走完主链。

**不要双击 `web/index.html`。** 浏览器会禁止 `file://` 页面读取 `data/*.json`，你只会看到一堆没有样式的文字；页面会给出提示。必须通过 `web_server.py` 打开。

部署到 Render/Fly 时，服务器已读 `PORT` 环境变量；`render.yaml` 里只需设 `DEEPSEEK_API_KEY`。

## 不出戏

- 文书默认显示**人话版**（游戏内翻译/复述），点「看原文」才看简牍原文；`[evidenced]/[inferred]`、简号、URL 都收进「考据」按钮，点开才出现。
- NPC 说人话，不拽文言文。prompt 明令「不要敢言之、伏惟、之乎者也；短句，像县衙同事」；服务器返回后再查一遍「敢言之/矣/焉得」等腔调，命中就换成人物自己的回退台词，日志记 `style:*`。
- NPC 嘴里没有「根据史料记载」「简牍记载」「秦代」「秦始皇」「公元前」这类词；命中即换成回退台词，日志记 `meta:*`。
- 案卷面板只写「已核/待核」，不写 `evidenced/inferred`；那张学术三分表留在 `research/evidence.md`。
- 开篇/结尾是叙述者和「案后记」，不是 NPC 嘴里的话；「为什么不是电影」放在文档里，不在游戏里讲。

## NPC 是怎样接 AI 的

每个 NPC 在 `game/data/npcs.json` 里有：身份、目标、`knowledge`（用白话写的可知事实，带 `source`）、`forbidden`（不可知）、说话风格、回退台词。服务器 `server/npc_server.py`：

1. 只把该 NPC 的可知事实、当前地点/时辰/在场者/玩家已得材料发给模型；
2. 要求模型只输出一个 JSON：`{"action":"speak|show|withhold|wait","speech":"...","source_refs":["S10"]}`；
3. 服务器做 schema 校验、出处过滤、禁知词守卫、文言腔守卫；
4. 游戏只把 `speech` 显示出来；**移动、给文书、记证据、驳/准都由游戏世界判定**，模型不能替玩家做事；
5. 每次调用写 `logs/npc_calls.jsonl`：prompt、原始输出、usage、延迟、估算费用、守卫结果。

NPC 说的是**现代白话**，不是秦代口语；`knowledge` 也全部改写成白话，避免模型跟着简牍腔跑。文书另有「人话版」，默认显示；点「看原文」才看简牍原文。

费用（截至本文写作时的 121 次计费调用）：输入 82,466 tokens，输出 26,122 tokens，估算 **US$0.0510**；其中 3 次 JSON 截断、3 次重试成功。日志在 `logs/npc_calls.jsonl`，可用 `curl /stats` 汇总。

## 证据分级

| 类型 | 例子 | 处理 |
|---|---|---|
| **evidenced** | 《封诊式·经死》验尸清单、《法律答问》贼杀/斗杀/四邻、《行书律》时辰 | 原文/出处卡；游戏内「考据」可查 |
| **inferred** | 丙的尸身细节、三十石亏空、丙妻的口供、里典那晚进仓 | 明确标注「推拟」，不冒充原简 |
| **invented** | 令史喜调迁陵、丙/丙妻/里典午、地图位置、交互规则 | 在 `research/evidence.md` 逐项说明「为了跑起来」 |
| **人话版** | 文书的现代白话翻译/复述、NPC 的现代口语 | 游戏内表现选择，不是史料原文；原文随时可切回 |

完整的“部件—状态—出处”表在 [`research/evidence.md`](research/evidence.md)；来源列表在 [`sources/processed/sources.md`](sources/processed/sources.md)；设计说明在 [`research/design.md`](research/design.md)。

## 已知限制

- **《封诊式·经死》是“式”（验尸模板），不是一桩真实案件**；丙、丙妻、里典午、三十石亏空都是剧情设定，标为 inferred/invented。
- 秦律的杀人分类（贼杀/斗杀/过失/死难审）在学界仍有讨论；游戏只取《法律答问》两条做机制，不把「四种死法」说成完整秦律。
- 地图是**示意性**的迁陵县城，不是考古复原；仓/乡/亭的相对位置为推拟。
- 6 个 NPC 的台词由模型生成，属 **invented/inferred**；模型只知道 `knowledge` 里的事实，但仍可能说错，游戏用守卫与回退兜底。
- **NPC 说的是现代白话，不是秦代口语**；文书的「人话版」是游戏内翻译，不是史料原文。这样做是为了让不了解秦制的读者能进入；原文和出处都保留在「看原文」「考据」里。
- 没有音频。Godot 版需要 Godot 4.7 运行；网页版不需要，`python3 server/web_server.py` 即可。
