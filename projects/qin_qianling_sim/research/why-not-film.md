# 为什么不是电影？

因为这件事的难处不在「谁杀的」，在「你把它写成哪一种死」。

电影可以这样拍：镜头扫过仓梁上吊着的尸体，里典说「自杀」，仓啬夫擦汗，丙妻哭。最后守丞提笔一批，案子结了。观众会记住一句：秦代基层靠文书办案。

但玩家要自己走一遍：

1. 看里典的报案，读《封诊式·经死》的验尸清单。
2. 去仓里验尸：舌出不出、绳痕是不是椒郁色、脚下离地多高、有没有屎尿、解绳后口鼻有没有气；再看后脑有没有别的伤。
3. 查仓里的账：少了三十石，丙是最后一个经手人。
4. 去都乡问丙妻：他说「账对不上，他们要拿我顶」；问里典：他那晚到底去没去过仓。
5. 去邮亭封案卷、记送郡时间。邮人得求你写早半刻——你写不写？
6. 回县廷交案卷，选：**自杀 / 贼杀 / 斗杀 / 死难审**；再决定把不把里典、四邻、仓啬夫写进去。

这六步不是「找凶手」。它是**决定哪些字进案卷**。同一具尸体，四种写法：

- **自杀**：案子结了，仓里的账没人查，丙妻和孩子暂时安全；三个月后，丙的弟弟递状纸。
- **贼杀**：立案，仓啬夫和里典被拘，三十石的账翻出来；你写对了，但没人谢你。
- **斗杀**：你以为能替人减罪，守丞一句「斗杀人，廷行事为贼」把它改成贼杀。
- **死难审**：你写「验不明白」，案卷送郡里，迟迟没有回音；你没冤枉人，也没替人申冤。

电影只能让你看其中一种；模拟让你在信息不全的时候自己选，然后在守丞的「按自杀结了 / 按他杀立了案 / 写成了斗杀 / 写了死难审 / 验尸不实」里看到后果。

## 一个只有模拟才有的瞬间

你验完尸，手里有五处证据：

- 舌出、绳痕、矢溺——像自杀；
- 后脑有淤伤——不像绳痕；
- 粮袋旁有血——现场不止一个人；
- 丙妻说「三十石，你填」——有人逼他；
- 里典说「我早上才发现」，可邻居看见他前一夜进了仓。

你可以写「自杀」，把后脑的伤解释成「摔倒磕的」；也可以写「贼杀」，把里典和仓啬夫都写进去；还可以写「死难审」，承认自己验不明白。**每一种写法都合法，但后果不一样。** 电影里的观众只能看主角选一种；模拟里的玩家要自己承担。

## 模拟没有替代什么

它不替代叙事。电影能把丙妻的哭、里典的慌、仓啬夫的算盘拍得更有情感；这份模拟只做一件事：让你在验尸格目、律令、口供之间，把一具尸体「写成」一份案卷。

如果观众只需要知道「秦代有验尸制度」，五分钟讲解就够了；如果要知道**验尸制度怎样把一具尸体变成一份责任分配书**，就得自己走一遍。

这也是我在 README 里写的：这不是「历史游戏」，是一个程序模拟。它的乐趣不在破案，而在看懂一套程序如何把「怎么死的」变成「该谁负责」。
