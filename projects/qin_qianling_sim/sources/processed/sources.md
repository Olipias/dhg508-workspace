# 来源列表

## 一手：简牍与律令

1. 睡虎地秦墓竹简整理小组：《睡虎地秦墓竹简》，北京：文物出版社，1990。
   - 《封诊式·经死》——吊死的验尸格目：舌出、绳痕、矢溺、头脚距离、死难审、问同居。
   - 《封诊式·贼死》——他杀尸体的验尸格式；以襦履诣廷。
   - 《法律答问》——贼杀/斗杀、「斗杀人，廷行事为贼」；四邻/典老连坐。
   - 《秦律十八种·仓律》——稟食标准、止稟/复稟、仓廪责任。
   - 《秦律十八种·行书律》——文书传递、起/到时辰、滞留追责。
   - 《封诊式·穴盗》——爰书格式、令史往诊。
   - 《封诊式·治狱/讯狱》——“先尽听其言而书之”。
   - 《效律》——衡石/桶/斗误差与赀甲/盾（背景卡）。
2. 陈伟主编：《里耶秦简牍校释》第一卷，武汉：武汉大学出版社，2012。
   - 16:9——渚里劾等十七户徙都乡，皆不移年籍。
   - 8:1345+8-2245——倉是、史感、稟人援出稟遷陵丞昌。
   - 8-217——倉是、史感、稟人堂出稟隸臣嬰。
   - 8:154——卅三年二月壬寅，邮人得行。
   - 8:157——启陵乡除里典/邮人，迁陵丞昌诘问。
   - 16:6——迁陵守丞敦狐告尉，走袑行尉（“三月”为整理者拟补）。
