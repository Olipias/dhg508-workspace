## 可执行试玩步骤

运行 `./play.sh --audio-driver Dummy`。使用当前源码，旧的导出包不会自动更新。

1. 新游戏观看或跳过CG，阅读教学简报，带面具撤离回安全屋。旧档完成教学后回屋会补播新版说明。
2. 走到书桌按E，浏览器搜“双羊尊”（系统输入法可用时直接输入；WSL可输入shuangyangzun按空格，再点搜索）。阅读并收集研究与档案；编号1936,1118.1也可检索。
3. 在电脑聊天发送“双羊尊”，阅读阿岚的C-17布展材料。推理板将馆藏档案与技术研究拖到右上框，选择“档案形制与工艺研究共同表明…”；再拖布展单，确认今晚展区。只有材料不选正确结论，不能出发。
4. 关闭电脑，P打开手机委托，点第二关“准备出发”，关手机，走到房门按E。只有一项推理时按钮应为“待推理”。
5. 两关实际地面和墙体均应正常显示；小地图初始仅入口，走进新房间后逐步增加，重进记忆保留。
6. 第二关可侦察撤离；取回主要文物后返回安全屋选择恶魔或接收方。主要文物不可普通出售，普通物品继续使用箱子/预约交易。

依据MANUAL_QA执行了可自动驱动的电脑/手机/房门/推理/存档与截图观感检查；没有将自动事件冒充真人试玩。音频听感、宿主Windows输入法合成窗口及真人剧情理解仍待用户试玩。WSL词表仅限项目关键词，不是通用拼音输入法。
